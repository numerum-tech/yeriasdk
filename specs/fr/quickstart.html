Un endpoint HTTP, une vue, un test dans l'application. Cette page suit le chemin le plus court ; les détails du protocole sont dans Intégration provider.

Ce dont vous avez besoin : un backend joignable en HTTPS depuis un téléphone, Node 18+ ou Python 3.10+, et un compte Yeria.

1. Générer votre paire de clés

La clé privée signe les vues que vous renvoyez. Elle ne quitte jamais votre serveur.

openssl genpkey -algorithm ed25519 -out service_private.pem
openssl pkey -in service_private.pem -pubout -out service_public.pem

L'algorithme doit être Ed25519. Le registre refuse toute autre clé.

2. Déclarer le service

Dans l'espace fournisseur, créez le service, renseignez son URL de base, et collez le contenu de service_public.pem dans le champ clé publique.

Notez l'identifiant du service : il sert à épingler l'audience des jetons utilisateurs que vous recevrez.

3. Installer le SDK

Le paquet porte un nom différent dans chaque langage, mais la même version du protocole : @numerum-tech/yeriasdk pour Node, yeriasdk pour Python.

npm i @numerum-tech/yeriasdk
pip install yeriasdk

Aucune dépendance native : l'installation ne compile rien. La signature Ed25519 s'appuie sur la bibliothèque standard des deux plateformes.

4. Configurer le backend

YERIA_BASE_URL=https://yeria.app
YERIA_APP_ID=votre-application
YERIA_SERVICE_ID=votre-service
SERVICE_ED25519_PRIVATE_KEY="$(cat service_private.pem)"

5. Renvoyer une vue

Le SDK sépare deux responsabilités : YeriaUI construit la vue et ne détient aucune clé ; YeriaApp détient la clé, signe la vue et vérifie les jetons entrants.

import express from 'express';
import { YeriaUI, YeriaApp } from '@numerum-tech/yeriasdk';

const app = new YeriaApp({
  appId: process.env.YERIA_APP_ID,
  baseUrl: process.env.YERIA_BASE_URL,
  privateKey: process.env.SERVICE_ED25519_PRIVATE_KEY,
});

const server = express();

server.get('/recharge', (req, res) => {
  const view = YeriaUI.createFormView('recharge', 'Recharge de compte')
    .setIntro('Service vérifié · paiement direct')
    .addPhoneField('msisdn', 'Numéro', true)
    .addNumberField('amount', 'Montant (FCFA)', true)
    .submitButton('Payer', 'POST');

  res.json(app.serve(view));
});

server.listen(8080);
import os
from fastapi import FastAPI
from yeriasdk import YeriaUI, YeriaApp, YeriaAppConfig

app = YeriaApp(YeriaAppConfig(
    app_id=os.environ["YERIA_APP_ID"],
    base_url=os.environ["YERIA_BASE_URL"],
    private_key=os.environ["SERVICE_ED25519_PRIVATE_KEY"],
))

server = FastAPI()

@server.get("/recharge")
def recharge():
    view = (
        YeriaUI.create_form_view("recharge", "Recharge de compte")
        .set_intro("Service vérifié · paiement direct")
        .add_phone_field("msisdn", "Numéro", True)
        .add_number_field("amount", "Montant (FCFA)", True)
        .submit_button("Payer", "POST")
    )
    return app.serve(view)

serve() renvoie l'enveloppe { payload, signature }. L'application vérifie la signature avec votre clé publique avant de rendre l'écran ; une vue non vérifiable est refusée.

6. Vérifier le jeton utilisateur

L'application appelle votre endpoint avec un jeton porteur émis par Yeria pour votre service. Vous le vérifiez vous-même : le SDK fournit des helpers, pas de middleware.

const auth = req.headers.authorization || '';
const bearer = auth.toLowerCase().startsWith('bearer ') ? auth.slice(7).trim() : '';
const user = await app.verifyUserToken(bearer, process.env.YERIA_SERVICE_ID);

La clé de signature de la plateforme est récupérée une fois puis mise en cache : les vérifications suivantes ne font aucun appel réseau.

7. Tester

Votre service n'est pas encore au catalogue. Tant qu'il n'est pas passé par la revue Yeria — et chaque fois qu'il est dépublié — il n'apparaît ni dans la recherche ni dans les listes publiques. Vous le trouverez dans l'application sous Mes services privés, et nulle part ailleurs.

Vous devez vous y inviter vous-même. Cette section liste les services auxquels on vous a donné accès : ouvrez donc votre service dans l'espace fournisseur, allez à l'onglet Accès, et invitez le compte que vous utilisez dans l'application. L'invitation arrive dans l'application, vous l'acceptez, et le service apparaît dans votre liste privée, avec la vue que sert votre backend.

Ouvrez votre service depuis l'application Yeria. L'écran décrit à l'étape 4 apparaît en rendu natif. Modifiez la vue, redéployez votre backend, rouvrez le service : l'écran a changé, sans passer par un store.
